# 使用说明

GD Pal 默认使用肥鱼 2D 伙伴。Windows 提供大厅、透明桌宠和悬浮通话，Android 使用触屏界面。每位伙伴分别保存设定、会话和外观，最多同时管理四位伙伴。

## 连接与聊天

在「连接设置」选择服务，填写 API 地址、模型名称和 Key。当前提供 DeepSeek、OpenCode Console / Zen、OpenCode Go、OpenRouter、OpenAI、Anthropic、Gemini 与自定义地址预设。高级设置可选择 Chat Completions、Responses、Messages 或 Gemini 接口格式；所选模型需由对应服务提供。

思考强度可以选择服务默认或接口支持的选项。服务默认不发送思考参数；Messages 接口需要设置输出额度，其余接口沿用服务默认额度。聊天、连接测试和 AI 整理共用连接配置。语音朗读使用可选 HTTP TTS，默认不启用。

聊天支持流式回复、停止、重试、历史搜索和会话切换。空输入时发送按钮显示「继续」，仅追加角色回复，控制指令不会成为用户发言。空会话产生实际内容后才保存。

中文或英文圆括号内的文字作为动作／旁白，不朗读。输入框的动作按钮可插入括号或包裹选中文字。角色画面上的点击可逐条播放已经解析的回复；到末尾后保持当前内容。

### 图片消息

Windows 和 Android 均可通过系统文件选择器添加 PNG、JPEG、静态 WebP，每条最多四张，可单独发图。Windows 还支持粘贴截图或复制的图片像素；Android 暂不支持图片剪贴板。发送前可预览和移除，聊天中的图片可以放大。

图片在本机处理后发送：最长边不超过 1600 像素，每张不超过 2 MB。一次模型请求最多携带最近四张图片，较早图片会标记为未附带。模型及服务必须支持识图。

## 人设、记忆与世界设定

「伙伴档案」编辑名字和人设；记忆页分别编辑长期记忆、活跃记忆；世界设定页编辑背景、人物关系和规则。保存后从下一次请求生效，新会话继续沿用。人设最多 4000 字，其余每份设定最多 16000 字。

这些设定是伙伴目录中的 Markdown 文件，可从界面打开、在外部编辑并重新载入。发送聊天和生成整理候选前会重新读取文件；界面检测到外部修改时会提示重新载入，避免覆盖。

## AI 整理

从聊天、人设、记忆或世界设定进入「AI 整理」，填写要求，跨会话选择聊天素材。模型将信息归入人设、长期记忆、活跃记忆或世界设定，生成可编辑候选条目；生成不会直接改写正式设定。

逐条「加入」或勾选后批量加入会追加到对应字段的最新内容，忽略的条目可以恢复待选。已加入或正文已存在的条目不会重复追加。素材较长时分批处理；要求、候选及审核状态会保存，完整返回可在界面查看。

勾选「同时整理已有记忆文件」后，模型会进一步结合已有长期记忆、活跃记忆、世界设定与新增信息，生成三份完整合并稿。也可以不选聊天，只整理已有文件。界面提供原文、可编辑合并稿、变更说明和冲突提示；点击「应用合并稿」后才写入，并先备份原文件。生成期间原文件被外部修改时会拒绝覆盖，需重新生成。人设仍逐条审核，不参与全文替换。

## 导入、导出与初始包

在「伙伴档案 → 导入导出」导出人设时，可选择附带世界设定和记忆。导入先预览，再创建新伙伴或覆盖当前伙伴勾选的字段。肥鱼初始包中的 `persona.zip` 可通过此入口导入；它提供普通初始人设，不包含个人记忆或聊天。

历史会话可以导出单段或全部记录 ZIP，也可从聊天菜单导出当前会话。导入会追加到当前伙伴，按来源指纹跳过重复记录，不会自动切换会话、整理内容或播放历史动作。

数据包统一为 v1，含清单、长度及 SHA-256 校验信息。**对话 ZIP 会携带消息中的图片附件**，不携带角色立绘、VRM、连接凭据或 Agent 配置。Android 导出含图会话时使用 ZIP，纯文字可导出 Markdown。

## 桌宠、衣装与外观

大厅的全身／近景构图与桌面模式独立保存。Windows 可选择全身桌宠或近景悬浮通话；通话模式不行走、不吸附边缘。大厅与桌面使用同一套动作／衣装环形菜单，较多动作分页显示。

肥鱼支持女仆装和睡衣，两套衣装各有全身、近景、行走、坐下和趴下资源。手动选衣装会自动锁定；解除锁定并允许 AI 选择衣装后，模型才可换装。等待回复期间手动修改衣装也会受到锁定保护。

桌宠拖近任务栏或普通窗口上沿松手可吸附。选择坐下或趴下时优先放到任务栏；已吸附时切换姿势保持支撑位置。横向拖动沿边缘滑动，竖向拖离则离开支撑面。切换到 DS 3D 后可使用已适配的骨骼动作，详见[角色与素材](assets.md)。

角色触控范围位于头部、肩部和手边的小圆区，可用「显示触控范围」查看。圈外点击推进已解析的回复；拖动、气泡和菜单操作不会重复推进。

「主题与外观」可调整亮／暗模式、主题色、浮层透明度，以及对白／旁白气泡开关。默认浮层透明度 75%，可调 50%～90%；这些设置在大厅、桌宠和移动界面共用。

关闭 Windows 大厅会收起到系统托盘，桌宠和聊天继续运行。单击托盘恢复大厅，也可通过托盘菜单退出程序。

## Android

Android 自动切换为触屏布局，横竖屏共用角色与会话，仅使用 2D 立绘，不创建桌宠窗口、系统托盘或 Agent 任务页。当前没有麦克风、语音识别或视频通话。

外部文件通过系统选择器导入，无需全部文件权限。勾选「在此设备记住 Key」后，凭据保存在本机应用私有目录；清除应用数据或卸载后需要重新配置。

Release APK 使用固定项目证书正式签名。此前的 debug APK 使用不同证书，切换时需先导出需要保留的人设和聊天，再卸载旧包、安装正式签名包。以后沿用同一发布证书的版本可覆盖升级。

## Agent 任务（Windows）

在 Agent 配置页选择已安装的 ACP 程序，填写参数和工作目录，再授权任务使用。脚本入口需要真实解释器与脚本参数；修改程序、参数或目录后需重新授权。

连接测试只进行握手。任务支持查看工具活动、回答额外权限请求、继续和取消；同一时刻执行一个任务，普通聊天可继续使用。重启后未完成任务标记为中断，由用户决定继续。

私密环境变量使用本机凭据存储，聊天凭据不会自动传给 Agent。工作目录不是系统沙箱；Agent 具有其自身文件、终端和网络能力，取消不会回滚已经发生的文件变化。
