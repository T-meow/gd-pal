# 角色与素材

## 肥鱼 2D 立绘

默认角色为蓝色肥鱼，静态立绘清单位于 `assets/characters/blue_whale/manifest.json`。当前清单引用 141 张图片，涵盖女仆装和睡衣、全身和通话近景、动作与表情；后续以清单实际内容为准。

清单保存图片路径、画布、可见边界、锚点、衣装和动作／表情映射。大厅构图与桌面模式独立，表现器仅使用当前衣装与视图存在的资源。两套衣装均支持左右行走、坐下、趴下和常用表情。

`images/` 不纳入 Git，图片及其导入缓存被忽略。构建源码时从对应 Release 的肥鱼初始包恢复 `assets/`，再由 Godot 生成导入资源。发布脚本严格按清单收集图片，不收集 `output/` 内的原稿、生成记录或预览页面。

Release 的 Windows 和 Android 程序已带齐图片；初始包中的 `persona.zip` 仅用于导入普通人设，图片目录用于源码构建，不通过人设导入界面安装。

图片来自 Codex image_gen 或 mxai Nano，生成来源见 `assets/characters/blue_whale/README.md`。修改或补充图片时同步更新清单中的画布、边界、锚点和衣装映射，效果由人工查看图片及运行画面确认。

## DS 3D 与动作

Windows 的内置 3D 外观使用 `assets/DS-desktop.vrm`。完整动作库只对已适配的 DS 模型指纹启用；其他 VRM 使用基础互动，不因骨骼同名直接视为兼容。

`assets/motions/npc/` 保存 52 个原始人形动作及来源记录，`assets/motions/ds_desktop/` 保存挥手、悬空提起和边缘趴靠三个桌面派生动作。运行时无需原动作工程，也不包含早期角色模型及其专用桌面动作。

DS 适配会移除模型不存在的眼球骨骼轨道，并修正髋部参考位置。每个伙伴独立播放动作。单次动作结束后返回待机，循环与静态姿势持续到下一次互动；「返回待机」可结束动作。

手动选择走路或跑步只播放原地动画，不自动移动窗口；窗口移动由桌面行为控制。部分坐卧动作仍需要家具支撑或缺少完整过渡，低位姿势更适合在桌面全身模式查看。鞋底、头发、衣服与支撑面的接触需人工确认。

## 更新动作库

`tools/motion-selection.json` 决定选用范围，保留项与新增项分开处理。已有运行资源可以直接构建；只有同步动作时才需要本机源库与原参考模型：

```powershell
node tools/sync-motions.mjs 'D:/路径/动作库' 'D:/路径/原动作库参考模型.vrm'
```

同步脚本核对参考模型指纹、动画哈希和许可证据，只复制选中的 Godot 动画及来源文件，不复制原模型或 GLB 网格。DS 桌面派生动作由 `tools/build-desktop-motions.gd` 基于默认 DS 模型重新生成。

`npc_motions.tres` 保存资源引用，`catalog.gd` 保存运行时名称、分类和播放方式，`manifest.json` 保存来源、裁切、转换、哈希和许可证据。更新时同时维护资源与清单，保留来源记录。
