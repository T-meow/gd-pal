# 记忆与陪伴 UI 预览

2026-10-12。沿用当前 GD Pal PC 深蓝灰主题和 1440×900 画布，先展示 Yumo 记忆与关系更新对应的界面。四张 SVG 均内嵌已有房间与角色示意素材，可单独打开，无网络依赖。

打开 `index.html` 可切换四页；SVG 和 PNG 是静态效果图，按钮未连接正式数据。2026-10-12 已按这套设计接入正式 Godot 界面和 ChatService，运行项目后可查看真实数据。

| 页面 | 设计内容 |
|---|---|
| `01-embedding-settings.svg` | 连接设置增加记忆检索页：开启语义检索、独立模型/地址/Key、更新索引；未配置时仍可关键词检索 |
| `02-memory-search.svg` | 回忆手册增加跨会话查找：自然语言搜索、经历类别、原话来源和查看/纠正/遗忘入口 |
| `03-relationship.svg` | 相处档案展示称呼、相处方式、明确习惯、进行中及已完成的约定；来源可追溯，无亲密度数值 |
| `04-companion-preset.svg` | 伙伴档案增加长期陪伴预设，填入主动/仅必要时澄清、120k 换段与12k原文交接；保存后生效 |

`overview.svg` / `overview.png` 为四页总览，所有展示内容为虚构样例。相处档案当前以查看来源为主，不设计没有来源的手动完成按钮。模型窗口容量继续放在更多上下文设置中。

编辑 `build.cjs` 后执行 `node build.cjs` 可重新生成 SVG。设置 `GD_PAL_SHARP_MODULE` 为已安装 sharp 的模块路径时，同时导出 PNG。`node preview.cjs` 可启动仅监听本机的预览页面。

本目录通过 `.gdignore` 隔离，不导入运行资源，不调用模型服务。正式界面使用 Godot 控件实现，具体接入与人工验收说明见 `../../docs/companion-ui-v0.2.md`。
