# GD Pal PC UI 交互原型

深色沉浸风格、角色通话近景、独立半透明对话栏。此目录是独立 Web 原型，通过 `.gdignore` 隔离；不加载正式 Godot、Yumo、角色或聊天存档。

## 打开

直接用现代桌面浏览器打开 `index.html`。全部资源在本地，无需安装依赖，无需联网。

也可以在此目录运行 `node preview.cjs`，使用终端打印的本机 URL。服务仅监听 `127.0.0.1`，默认自动选择空闲端口。主设计尺寸为 1440×900，也安排了 1280×800 和 960×640 布局；低于 960×640 时保留最小画布。

## 可以体验的内容

- 通话：中文输入、预设流式回复、停止、清空示例、快捷话题、互动反馈、收起与展开对话栏。Enter 换行，Ctrl+Enter 发送；输入法组合期间不发送。
- 房间：夜间书房、暖光卧室、雨夜客厅。切换背景和场景信息，保留当前示例消息与输入。
- 桌宠：自由站立、窗口上沿坐姿、任务栏上沿坐姿；拖动模拟窗口时角色跟随，自由站立时可拖动角色。悬停显示聊天、切换坐靠、返回通话工具。窗口标题栏聚焦后可用方向键移动，Shift 加速。
- 角色、剧情、回忆：左侧入口展示示例资料；正文和操作均在侧栏内。桌宠气泡与通话共用本轮内存里的对话。
- 声音只展示开关状态，不连接音频设备或模型。示例对白与回忆为虚构内容。

房间、侧栏开关和桌宠姿态保存在专用 `localStorage` 键 `gd-pal-desktop-design-v1`；浏览器禁止本地存储时仍可使用，只是不记住偏好。对话和草稿只存于本次页面内存。

## 可编辑资源与扩展

- `index.html`：界面结构与图标；`styles.css`：配色、布局和控件；`app.js`：原型行为。
- `rooms.js`：房间清单。新增房间只需添加 SVG/PNG/JPEG 资源和一个条目，`id` 唯一，`kind` 使用 `image`；同时填写名称、缩略图、时间、场景说明及示例回复等展示字段。
- `assets/rooms/`：三间原创 SVG 房间。采用形状、路径、渐变及图案，无外部图片、字体、滤镜或依赖；家具与强对比区域尽量放在两侧。
- `assets/character-*.svg`：原创 SVG 示意人物「凛」，包含站姿、坐姿、通话近景、头像。`build-character.cjs` 是共用源；修改后执行 `node build-character.cjs` 重新生成，避免不同姿态的脸和服装风格漂移。

背景宿主与角色、UI 分层。`app.js` 中 `backgroundRenderers[kind]` 接收房间条目，返回 `Promise<{ element, dispose() }>`；未来可增加 `scene3d` 渲染适配器，将 canvas 放在背景宿主中，释放时清理 3D 资源。当前只实现图片适配，不包含 3D 引擎；这也是以后迁移至 Godot 背景宿主时的职责边界，不改动正式 Godot API。

坐姿图的坐靠锚点为 `(270, 535)`，视图尺寸 `540×780`；站姿尺寸 `540×1040`。桌宠演示将臀部锚点对齐窗口或任务栏上沿，腿自然下垂。这里的坐靠是浏览器内模拟，不控制真实 Windows 窗口。

## 验证边界

开发时只做 JavaScript 语法、SVG/XML 格式和静态资源引用检查。没有自动截图、视觉巡检或操作验收。请人工体验：角色有无被对话遮挡、三个房间的明暗与对白清晰度、窗口移动时的坐靠效果。

正式接入 Godot 前建议先建立 Git 基线；开始本轮工作时项目目录未检测到 Git 仓库。
