# 蓝色肥鱼

静态 2D 角色包 v1，包含女仆与睡裙两套衣装、全身和通话近景、动作与表情。`manifest.json` 是当前图片路径、画布、锚点和映射的唯一清单；发布脚本按该清单收集全部立绘。

`images/` 及图片导入缓存不纳入 Git，随 Release 的肥鱼初始包分发。源码使用者将初始包中的 `assets/` 合并到项目根目录后，由 Godot 重新导入图片。Windows 和 Android 发布程序已包含这些立绘。

初始包另含可在「伙伴档案 → 导入导出」导入的 `persona.zip`，采用普通人设，不包含个人聊天、记忆或连接设置。素材文件夹不属于人设 ZIP 的导入格式，无需在发布程序中手动导入图片。

基础、换装与表情图片使用 Codex image_gen 或 mxai Nano 生成。原始生成记录和提示词保留在本机 `output/imagegen/`，不作为源码或初始包发布。直接查看 `images/` 中的图片确认效果。
