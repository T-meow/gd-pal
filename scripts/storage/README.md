`PalSessionStore` 将至多四个角色档案保存到 `user://pal_session.json`，先写临时文件再重命名替换。身份使用随机 128 位标识，外观切换与重新启动后保留。

保存角色名称、模型路径、2D/3D 选择、鼠标注视、缩放、位置、慢走、人设与已有会话数据。模型本体不复制进存档；外部文件需要继续位于保存的路径。启动时模型加载失败会在大厅回退到 2D 并显示错误；在档案中更换模型失败则保留原外观。

`load_session()` 区分有效的空列表与缺失/损坏文件，移除全部角色后不会在下次启动自动重新添加。选中伙伴单独保存在 `user://ui_state.cfg`。`GD_PAL_TEST=1` 时大厅不读写正式会话和 UI 配置，验证器另行隔离 APPDATA；恢复测试仅使用显式指定的临时路径。
