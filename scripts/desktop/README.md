`PalDesktopWindow` 为一位伙伴提供独立透明原生窗口。`PalUiCoordinator` 将同一角色视口在大厅、桌面窗口与隐藏停放容器间重新挂载，保留档案、骨骼、表情和行为对象。宿主为 `hall`、`desktop` 或 `parked`，每位伙伴只有一个实例。

从大厅“放到桌面”会保留主窗口并显示召回入口；选择伙伴或点击“大厅”把该伙伴带回大厅，原大厅伙伴进入停放区，其他桌宠继续运行。“全部召回”关闭所有桌面宿主，将当前选中伙伴带回大厅，其余停放。启动时恢复选中伙伴到大厅，桌面宿主本身不跨进程恢复。

支持拖拽、滚轮缩放、右键菜单、气泡和可选慢走。全局鼠标与按键通过 C# 查询，拖拽越出窗口后仍可在松手时结束。工作区坐标允许负值，恢复时钳制到可用屏幕。

3D 自动慢走时，镜头根据左右移动方向平滑转到对应侧面，角色面朝行进方向；到屏幕边缘折返同步转向。暂停散步、打开菜单、拖动或互动时停止自动行走并恢复正面镜头。趴靠姿势使用独立固定构图，不继承行走镜头。

`PalChatWindow` 是单独可聚焦的聊天气泡外壳，跟随桌宠，靠近工作区边缘时换侧；可展开、收起和调整大小。聊天内容与输入框复用该伙伴唯一的 `PalConversationPanel`，切换宿主不停止回复，按角色和会话保留当前进程内的草稿与阅读位置。收起气泡上的设置图标可以直接唤起大厅中的连接面板；其他管理入口由协调层在大厅内打开，伙伴保持在桌面。

原生桌宠不获取键盘焦点。后台回复更新摘要和未读，不自动展开或抢焦点；展开对应聊天后清零未读。Windows 独立运行时关闭大厅收起到托盘，最小化继续保留任务栏窗口。`PalSystemTray` 管理通知图标和原生菜单，Windows 桥接层隐藏主 HWND，保持独立桌宠、聊天和托盘回调；恢复时重新启用大厅渲染。从托盘退出前恢复大厅并检查回复、草稿与未保存编辑。无托盘或嵌入预览时关闭大厅执行退出，关闭聊天气泡仅将其收起。

Windows `SetInputRegions()` 使用保守模型包围盒与可见 UI 区域创建窗口区域，并最多每秒检查十次，不回读 GPU 图像。该区域同时裁剪绘制和输入，不能作为逐像素命中。透明合成、跨应用点击和不同 DPI 的实际效果仍需桌面验收。

默认 3D 角色 DS支持趴在可见的任务栏上沿和普通窗口上沿。拖到上沿附近松手自动依附，也可在右键菜单选择“趴在任务栏”；任务栏吸附基础距离为 160 像素。趴着时横向拖动可沿边缘滑动，到端点自动停住；只有竖向拖动超过基础阈值 90 像素才会提起，两个距离都随角色放大而增加。滑动后松手保留位置和姿势；主动提起后的这次松手不会立即重新吸附，下次拖动可再次趴靠。“离开边缘”或播放其他动作也可脱离。趴靠期间暂停自动散步，滚轮缩放保留接触点；触摸只给表情反馈，不强制站起来。

`GetDesktopSurfaces()` 缓存 150ms 的原生窗口查询，使用 DWM 可见边框、窗口句柄和所属进程标识，过滤自身窗口、最小化、隐藏及 cloaked 窗口，按前后顺序扣除被遮挡的上沿。保存的是相对目标窗口的水平位置；目标移动时跟随，目标关闭、最小化、当前依附点被遮挡或屏幕空间不足时脱离并回待机。依附关系只在当前进程保留，不写入存档。

只支持有足够可见空间的水平上沿；最大化窗口的屏幕顶部、竖向任务栏和自动隐藏后不可见的任务栏不作为趴靠面。其他 VRM 尚无匹配的趴靠动画，相关菜单禁用。姿势使用现有俯卧翘腿素材调整朝向，接触平面通过表现器投影到物理桌面坐标。

原生边框与 cloaked 属性使用微软文档中的 [DWMWINDOWATTRIBUTE](https://learn.microsoft.com/windows/win32/api/dwmapi/ne-dwmapi-dwmwindowattribute)。当前采用可见矩形区间，尚不处理异形窗口的逐像素遮挡。

统一自动检查使用 `tools/validate.ps1 -GodotPath <Godot .NET 路径>`；它隔离数据并检查资源、当前页面、立绘换装、2D／3D 切换和桌宠宿主转移。实际窗口、显示缩放、多屏、中文输入法与焦点需要人工确认，见[开发与发布](../../docs/development.md#日常开发)。
